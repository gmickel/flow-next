# Question

This route is read-only: edit no files and write no fix. If the answer implies work, name the route it would take in plain words and stop.

## How or why questions

Answer from the code, git history, and closed specs with concrete citations, marking each claim as read directly or inferred so the reader knows what is proven versus deduced.

## Captured artifacts

When handed a profile, trace, heap snapshot, or crash dump with a why question, diagnose from the artifact itself using tools already available on the machine; install nothing, and if nothing present can read the format, say so and name the export or live reproduction needed. Map findings to source, note where the checkout has changed since the recording, state whether the cause is confirmed or only the strongest supported hypothesis, and quote sparingly when a dump may hold secrets or personal data.
