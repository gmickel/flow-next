Shared blocks — `Pre-Question Taxonomy` and `Interview Guidelines` — live in [questions-shared.md](questions-shared.md). Read that first.

## Check the spec for

Ask about one of these only when the spec leaves it unclear, the code does not answer it, and the question passes the one test in SKILL.md. Technical detail, performance and edge cases that implementation, review and QA will surface are left to them.

- An irreversible data or contract change (a data model, a migration, a public contract).
- An external interface.
- A security boundary.
