# Bitbucket Cloud pull requests (gated reference)

> Read from workflow.md when the snapshot's `forge` is `bitbucket`.

Land does not merge Bitbucket pull requests yet. Stop before any read, repair or merge with
`LAND_VERDICT=NEEDS_HUMAN prs=1 pr=<url> reason="land is not supported on Bitbucket Cloud yet"`,
so the person merges it on Bitbucket.
